# 🚌 Bus Ticket Reservation System

A beginner-friendly Bus Ticket Reservation System developed using **C programming language** as a college project for the subject **Logical Thinking and Problem Solving**.

## 📌 About the Project

This project is designed to manage basic bus ticket reservation operations through a simple menu-driven console interface.

Users can check available seats, book tickets, cancel reservations, search for tickets, and display all booked tickets.

## ✨ Features

- Display available seats.
- Book a bus ticket.
- Cancel an existing reservation.
- Search tickets using seat numbers.
- Display all booked tickets.
- Simple and user-friendly menu.

## 🛠️ Technologies Used

- Programming Language: C
- Compiler: GCC
- Libraries: `stdio.h`, `string.h`
- IDE: VS Code

## 📚 Concepts Used

- Variables and Data Types
- Arrays
- Strings
- If-Else Statements
- Switch Case
- For Loop
- Do-While Loop
- Functions

## 🚀 How to Run

**Step 1:** Clone the repository.

```bash
git clone https://github.com/sakshamchouhan945/Bus-Ticket-Reservation-system.git
```

**Step 2:** Open the downloaded project folder.

**Step 3:** Compile the C program.

```bash
gcc "Bus Ticket Reservation System.c" -o bus_reservation
```

**Step 4:** Run the program.

For Windows:

```bash
bus_reservation.exe
```

For Linux:

```bash
./bus_reservation
```

## 📋 Main Menu

1. Display Available Seats
2. Book a Ticket
3. Cancel a Ticket
4. Search a Ticket
5. Display All Bookings
6. Exit

## 🎯 Project Objective

The objective of this project is to apply basic C programming concepts to solve a real-world problem and improve logical thinking and problem-solving skills.

## ⚠️ Limitations

- Supports only 10 seats.
- Fixed ticket price of ₹500.
- Booking data is temporary and is not saved after closing the program.
- Uses a console-based interface.

## 🔮 Future Improvements

- Permanent data storage using file handling.
- Multiple bus routes and destinations.
- Passenger contact information.
- Unique ticket booking IDs.
- Different ticket prices.
